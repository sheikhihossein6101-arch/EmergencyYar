# اورژانس‌یار — مدیریت تاریخ دارو و تجهیزات

اپ اندروید فارسی برای ثبت موجودی داروها و تجهیزات اورژانس پیش‌بیمارستانی.

## امکانات نسخه اولیه
- ثبت، ویرایش و حذف دارو و تجهیزات
- ثبت تعداد و محل نگهداری
- ثبت تاریخ انقضا با تقویم شمسی یا میلادی
- هشدار داخل برنامه برای اقلام منقضی و اقلامی که تا ۹۰ روز آینده منقضی می‌شوند
- جست‌وجو و فیلتر
- ذخیره محلی با SQLite و استفاده بدون اینترنت

## ساخت APK
1. پوشه پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync کامل شود (این پروژه برای دریافت وابستگی‌ها به اینترنت نیاز دارد).
3. از منوی **Build > Build APK(s)** استفاده کنید.
4. فایل APK در مسیر `app/build/outputs/apk/debug/` ساخته می‌شود.

## نکات مهم
- این نسخه هشدارها را داخل برنامه نشان می‌دهد؛ اعلان خودکار در پس‌زمینه هنوز اضافه نشده است.
- اطلاعات فقط روی همین گوشی ذخیره می‌شود؛ برای جلوگیری از از دست رفتن اطلاعات، نسخه پشتیبان جداگانه تهیه کنید.
- این اپ ابزار مدیریت موجودی است و جایگزین بررسی پروتکل‌های درمانی، سلامت بسته‌بندی یا تأیید مسئول دارو/تجهیزات نیست.
- قبل از استفاده عملیاتی، تاریخ‌ها و عملکرد برنامه را روی چند مورد نمونه آزمایش کنید.


## ساخت APK آنلاین با GitHub Actions (بدون Android Studio)
1. در GitHub یک حساب بسازید و یک مخزن جدید (Repository) ایجاد کنید؛ برای حفظ حریم خصوصی، آن را Private بگذارید.
2. فایل ZIP پروژه را روی کامپیوتر یا گوشی استخراج کنید.
3. تمام محتویات داخل پوشه پروژه را به مخزن GitHub بارگذاری کنید، به‌طوری‌که `settings.gradle.kts` در ریشه مخزن باشد و پوشه `.github/workflows/build-apk.yml` نیز بارگذاری شود. توجه کنید بعضی ابزارهای آپلود فایل‌های مخفی مثل `.github` را پنهان می‌کنند.
4. در مخزن، وارد تب **Actions** شوید. اگر پیام تأیید فعال‌سازی workflow آمد، آن را تأیید کنید.
5. از فهرست سمت چپ **Build Orژانس‌یار APK** را انتخاب کنید و روی **Run workflow** بزنید. همچنین هر بار که روی شاخه `main` تغییرات ثبت شود، ساخت خودکار اجرا می‌شود.
6. پس از پایان موفق اجرا، اجرای workflow را باز کنید و در بخش **Artifacts** فایل `orژانس-yar-debug-apk` را دانلود کنید. فایل دانلودی ZIP است؛ آن را استخراج کنید تا `app-debug.apk` را ببینید.
7. APK را به گوشی منتقل کنید. اگر اندروید اجازه نصب نداد، فقط برای برنامه‌ای که با آن فایل را باز می‌کنید اجازه نصب برنامه ناشناس بدهید. این فایل debug برای آزمایش است و برای انتشار عمومی/استفاده عملیاتی باید امضا و آزمایش شود.

نکته: GitHub Actions برای ساخت به اینترنت نیاز دارد تا Gradle و وابستگی‌های اندروید را دریافت کند. قبل از استفاده واقعی، برنامه و تاریخ‌های شمسی/میلادی را با داده‌های نمونه بررسی کنید.
